节点目录 ​

LiteGraph 内置 10 个节点包，共 92 个节点；核心另有 3 个内建节点（图输入/输出与子图），合计 95 个节点类型。

节点包都是可选插件，需要显式安装：install(LiteGraph) 或 LiteGraph.use(install)；聚合包 @gausszhou/litegraph 会自动安装全部节点包。
